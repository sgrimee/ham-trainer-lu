---
title: Das Dezibel (dB)
---

Im Funk vergleicht man ständig Leistungen: Wie viel stärker ist dieser
Sender? Wie viel geht in diesem langen Kabel verloren? Um das zu sagen,
benutzt man das **Dezibel**.

## Ein Vergleich, keine Leistung

Das **Dezibel** (Zeichen **dB**) misst keine Leistung: Es **vergleicht
zwei Leistungen**. Es sagt, um wie viel die eine stärker (oder schwächer)
ist als die andere.

Zwei Merkwerte reichen für den Anfang:

- **+3 dB** heißt etwa **doppelt so viel** Leistung;
- **+10 dB** heißt **zehnmal so viel** Leistung.

Und **0 dB** heißt „gleich“: Die beiden Leistungen sind gleich groß.

## Addieren statt malnehmen

Das ist der Trick beim Dezibel: Wenn man dB **addiert**, werden die
Leistungen **malgenommen**.

- +6 dB = 3 dB + 3 dB → 2 · 2 = **4-mal so viel**;
- +13 dB = 10 dB + 3 dB → 10 · 2 = **20-mal so viel**.

## In die andere Richtung: die Verluste

Eine **negative** Zahl von dB heißt „weniger“. Ein Antennenkabel ist nicht
perfekt: Es verliert unterwegs etwas Leistung. Verliert es **3 dB**, kommt
nur die **Hälfte** der Leistung an der Antenne an: Von einem 50-W-Sender
kommen nur noch 25 W an.

**Beispiel:** Ein Verstärker macht aus einem Signal von 5 W eines von
50 W. Um wie viel dB hat er es verstärkt? 50 : 5 = zehnmal so viel:
**+10 dB**.

> **Achtung:** Das dB ist **keine** Einheit der Leistung wie das Watt.
> „10 dB“ allein heißt nicht 10 W, sondern „zehnmal so viel wie etwas“. Man
> muss immer wissen, **womit** man vergleicht.
