Der berühmteste dieser Codes ist der **Q-Code** (auch **Q-Schlüssel**
genannt). Er ist über hundert Jahre alt und stammt aus der Telegrafie der
Schiffe; Funkamateure benutzen ihn jeden Tag.

## Drei Buchstaben, die mit Q anfangen

Jeder Code besteht aus **drei Buchstaben**, und der erste ist immer ein
**Q**: QRS, QTH, QSL … Fast kein Wort beginnt mit einem Q, auf das kein U
folgt: So verwechselt man einen Q-Code nicht mit einem gewöhnlichen Wort.

## Eine Antwort oder eine Frage

Jeder Code hat **zwei Formen**:

- **allein** ist er eine **Antwort** oder eine **Mitteilung**: eine
  Information oder etwas, worum man den anderen bittet;
- mit einem **Fragezeichen** dahinter wird er zu einer **Frage**.

Nehmen wir **QRS**:

<figure>
<table>
<tr><th>Code</th><th>Bedeutung</th></tr>
<tr><td><b>QRS</b></td><td>Senden Sie langsamer.</td></tr>
<tr><td><b>QRS?</b></td><td>Soll ich langsamer senden?</td></tr>
</table>
<figcaption>Derselbe Code, ohne und mit Fragezeichen.</figcaption>
</figure>

Schau dir die Frage genau an: Wenn der Code eine **Aufforderung** ist
(„Senden Sie …“, „Stellen Sie … ein“), dann ist seine Form mit „?“ eine
Frage **über dich selbst**: „**Soll ich** …?“. Frage ich dich „QRS?“ und
du antwortest „QRS“, dann heißt das Ja: Ich soll langsamer senden. So
schreibt die ITU den Q-Code, und so steht er im Prüfungskatalog.

> **Achtung:** Die Tabelle im Leitfaden des ILR, den es nur auf Französisch
> gibt, stellt diese Fragen anders, sinngemäß: „Sollen **Sie** …?“. Beide Formen sind
> in der Prüfung richtig. In diesem Kurs lernst du die Form der ITU:
> „Soll ich …?“.

## Ein Code und eine Angabe

Hinter den Code kann man eine Angabe setzen: ein Rufzeichen, eine Uhrzeit,
eine Frequenz. Uhrzeiten gibt man in **UTC** an, der Weltzeit, die auf der
ganzen Welt gleich ist. In Luxemburg zieht man im Winter eine Stunde ab, im
Sommer zwei: 14:00 Uhr in Luxemburg im Sommer sind 12:00 UTC.

> **Merke:** Q + zwei Buchstaben. **Allein**: eine Antwort oder eine
> Mitteilung. **Mit „?“**: eine Frage – bei einer Aufforderung
> „Soll ich …?“.
