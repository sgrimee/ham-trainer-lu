Plan : Q + deux lettres ; suivi d'un « ? », le code devient une question. Écart §1.3 (Q448, Q449, vérifié 2026-09-25) : le catalogue suit la convention de l'UIT, où « QRT? » est la question que je pose sur ce que moi je dois faire (« Dois-je cesser la transmission ? ») ; le tableau du guide écrit « Devez-vous… ? ». On enseigne la convention de l'UIT, et on dit que les deux formulations sont officielles.
