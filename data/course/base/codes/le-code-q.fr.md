Le plus célèbre de ces codes, c'est le **code Q**. Il a plus de cent ans
et vient de la télégraphie des bateaux ; les radioamateurs l'utilisent
tous les jours.

## Trois lettres qui commencent par Q

Chaque code est fait de **trois lettres**, et la première est toujours un
**Q** : QRS, QTH, QSL… Presque aucun mot ne commence par un Q qui n'est
pas suivi d'un U : on ne confond pas un code Q avec un mot ordinaire.

## Une réponse, ou une question

Chaque code a **deux formes** :

- **seul**, c'est une **réponse** ou un **avis** : une information, ou
  quelque chose qu'on demande à l'autre de faire ;
- suivi d'un **point d'interrogation**, il devient une **question**.

Prenons **QRS** :

<tr><td><b>QRS</b></td><td>Transmettez plus lentement.</td></tr>
<tr><td><b>QRS?</b></td><td>Dois-je transmettre plus lentement ?</td></tr>
</table>
<figcaption>Le même code, sans et avec point d'interrogation.</figcaption>
</figure>

Regarde bien la question : quand le code donne un **ordre**
(« Transmettez… », « Cessez… »), sa forme avec « ? » est la question
qu'on pose **sur soi-même** : « **Dois-je** … ? ». Je te demande QRS? ;
si tu me réponds QRS, c'est oui : je dois ralentir. C'est ainsi que l'UIT écrit
le code Q, et c'est la forme du catalogue de l'examen.

> **Attention :** le tableau du guide de l'ILR écrit ces questions
> autrement : « **Devez-vous** … ? ». Les deux formulations sont
> officielles. Dans ce cours, on apprend celle de l'UIT, « Dois-je … ? ».

## Un code, plus une précision

On peut ajouter une précision après le code : un indicatif, une heure,
une fréquence. Les heures se donnent en **UTC**, le temps universel, le
même pour le monde entier. Au Luxembourg, il faut retirer une heure en
hiver, deux en été : 14 h 00 à Luxembourg en été, c'est 12:00 UTC.

> **À retenir :** Q + deux lettres. **Seul** : une réponse ou un avis.
> **Avec « ? »** : une question — pour un ordre, « Dois-je … ? ».
