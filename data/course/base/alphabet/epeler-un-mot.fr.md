Plan : Lettre par lettre, sans les accents (í → India) ; les pièges : les lettres doubles, les lettres muettes, et le mot demandé plutôt que le mot connu (Zylophon, pas Xylophone). Q443 : la réponse du catalogue écrit JULLIET, une faute ; la note le dit.
