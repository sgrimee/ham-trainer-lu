# Glossary FR → DE (specs/LEARN-DE.md §4.1)

Built 2026-09-27 from the paired `text.fr` / `text.de` of the 77 BASE
questions and the German audit (LEARN-DE §3.3). **DE** is the word the
lessons use: the German catalogue's, unless marked. "Also" lists the other
forms a lesson names once, where the German exam or German sources use
them. ⚠ marks a catalogue word the audit found wrong: the lesson uses the
right word and names the exam's.

Add a term the first time a module needs it, with the question it comes
from; never change one a finished module uses without updating that module.
